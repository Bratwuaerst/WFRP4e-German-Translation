# WFRP4e-German-Translation
German translation of the Warhammer Fantasy Roleplay 4E Foundry System.

Dieses Repository enthält die deutschen Übersetzungsdateien für das Warhammer Fantasy Roleplay 4th Edition System für Foundry VTT.

## Foundry VTT Installation (Manifest‑URL)

Du kannst dieses Modul in Foundry VTT über die module.json manifest‑Datei installieren. Verwende den folgenden Raw‑GitHub‑URLs als Manifest‑URL beim Installieren:

- Version 0.1.0
  https://github.com/Bratwuaerst/WFRP4e-German-Translation/releases/download/v0.1.0/module.json

Schritte:
1. In Foundry: Setup (oder Configuration & Setup) → Add‑on Modules → Install Module.  
2. Füge eine der Manifest‑URLs oben in das Feld "Manifest URL" ein.  
3. Klicke auf Install.

Hinweise:
- Verwende die Commit‑URL, wenn du eine feste, reproduzierbare Version willst. Verwende die main‑URL, wenn du automatisch die neuesten Änderungen erhalten möchtest.
- Für stabile Releases empfiehlt es sich, ein Tag/Release zu erstellen und die Raw‑URL des Tags zu verwenden.
- Foundry vergleicht die "version" in module.json für Update‑Prüfungen — bei einer neuen Version die version erhöhen.
- Stelle sicher, dass raw.githubusercontent.com vom Foundry‑Server erreichbar ist und HTTPS verwendet wird.
